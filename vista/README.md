# فيستا إيفينت — كوش خطوبة وكتب كتاب وتنسيق حفلات

موقع كامل للبراند + لوحة تحكم. HTML و CSS و JavaScript خام، من غير أي build ولا مكتبات خارجية ولا أي طلب لسيرفر بره الموقع.

## التشغيل

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الملفات

```
index.html              الموقع
admin.html              لوحة التحكم
assets/css/style.css    ستايل الموقع
assets/css/admin.css    ستايل اللوحة
assets/css/fonts.css    تعريفات الخطوط
assets/fonts/           خطوط Noto Kufi Arabic و Playfair Display مستضافة محليًا
assets/js/data.js       البيانات (المعرض، الكوش، الخدمات، الإعدادات)
assets/js/store.js      طبقة التخزين
assets/js/app.js        منطق الموقع + «صمّم كوشتك»
assets/js/admin.js      منطق اللوحة
assets/img/             صور الأعمال + اللوجو + صورة المشاركة
```

## «صمّم كوشتك» — أهم حاجة في الموقع

العميلة بتختار ثلاث حاجات: **الشكل** (دائرية / متقاطعة / منسدلة)، **لون الإضاءة**
(أزرق / أخضر / بنفسجي / دافي)، و**الورد** (أبيض / بدون).

الموقع بيدوّر في المعرض على **صورة حقيقية من شغل البراند** بنفس التوليفة ويعرضها.
لو مفيش صورة بنفس الثلاثة بالظبط، بيقرّب: بيجرّب الشكل + اللون، وبعدين الشكل لوحده،
وبيكتب على الصورة **«أقرب حاجة لاختيارك»** عشان ميوعدش بحاجة مش موجودة.

الزرار بيبعت اختيار العميلة على واتساب جاهز.

**التصنيف ده بيتظبط من اللوحة:** تبويب **المعرض ← تعديل الصورة**، فيه ثلاث قوايم
(الشكل، الإضاءة، الورد). أي صورة جديدة تترفع لازم تتصنّف عشان المصمّم يلاقيها.

## الأسعار

مقفولة افتراضيًا وبيظهر مكانها **«السعر عند الطلب»**.
لو حبيت تظهرها: **الإعدادات ← إظهار الأسعار في الموقع**، وبعدين اكتب سعر كل كوشة
من تبويب **الكوش**.

## صورة المشاركة (الثامبنيل)

`assets/img/og-cover.jpg` مقاس 1200×630، ومربوطة في `<head>` عن طريق `og:image`.

**مهم:** الروابط في `index.html` مكتوبة بدومين `https://vista-event.vercel.app`.
لو رفعت الموقع على دومين تاني، غيّره في كل أماكنه عشان الثامبنيل يظهر:

```bash
sed -i 's|vista-event.vercel.app|الدومين-بتاعك.com|g' index.html
```

## التخزين

كل البيانات في `localStorage` تحت المفتاح `vista.v1`.
مفيش سيرفر ولا داتابيز — الموقع كله ستاتيك.
