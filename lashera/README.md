# لاشيرا ستور — زيت الشعر واللحية التركي

متجر تعريفي كامل للبراند + لوحة تحكم. HTML و CSS و JavaScript خام، من غير أي build أو مكتبات خارجية ولا أي طلب لسيرفر بره الموقع.

## التشغيل

افتح `index.html` مباشرة، أو شغّل سيرفر محلي:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الملفات

```
index.html                الموقع
admin.html                لوحة التحكم
assets/css/style.css      ستايل الموقع
assets/css/admin.css      ستايل اللوحة
assets/css/fonts.css      تعريفات الخطوط
assets/fonts/             خطوط Alexandria و Marcellus مستضافة محليًا
assets/js/data.js         البيانات الأساسية (المنتجات، المكونات، المعرض، الإعدادات)
assets/js/store.js        طبقة التخزين المشتركة
assets/js/app.js          منطق الموقع + السلة
assets/js/admin.js        منطق اللوحة
assets/img/               صور المنتجات والمعرض + اللوجو + صورة المشاركة
```

## الدخول للوحة

`admin.html`

| الحقل | القيمة |
|---|---|
| رقم الإدارة | `+962782340514` |
| كلمة السر | `123456` |

الرقم وكلمة السر بيتغيّروا من تبويب **الإعدادات** جوه اللوحة.

## اللوحة بتعمل إيه

- **المنتجات** — إضافة وتعديل وحذف وترتيب، مع رفع صورة من الجهاز والمقاسات والشارة.
- **المعرض** — نفس الحاجة للصور، والوصف اللي بيظهر تحت كل صورة.
- **الطلبات** — كل طلب جاي من الموقع (من الفورم أو من السلة) بيتسجّل هنا، وفيه تصدير CSV.
- **الإعدادات** — بيانات التواصل والنصوص، وكلمة سر اللوحة، ونسخة احتياطية JSON.

## الأسعار

الأسعار مقفولة افتراضيًا وبيظهر مكانها **«السعر عند الطلب»**.
لو حبيت تظهرها: **الإعدادات ← إظهار الأسعار في الموقع**، وبعدين اكتب سعر كل منتج من تبويب المنتجات.
لما تكون مفتوحة، إجمالي السلة بيتحسب لوحده.

## السلة والطلب

- كل منتج ليه مقاسات، واللي تختاره بيتحفظ مع المنتج في السلة.
- السلة محفوظة في المتصفح، فلو العميل قفل الصفحة ورجع بيلاقي طلبه.
- زرار «اتمم الطلب» بيفتح واتساب برسالة فيها كل المنتجات والكميات.

## صورة المشاركة (الثامبنيل)

`assets/img/og-cover.jpg` مقاس 1200×630، ومربوطة في `<head>` عن طريق `og:image`.

**مهم:** الروابط في `index.html` مكتوبة بدومين `https://lashera-store.vercel.app`.
لو رفعت الموقع على دومين تاني، غيّر الدومين ده في كل أماكنه في `<head>` عشان الثامبنيل يظهر.

```bash
sed -i 's|lashera-store.vercel.app|الدومين-بتاعك.com|g' index.html
```

## التخزين

كل البيانات في `localStorage` تحت المفتاح `lashera.v1`، والسلة تحت `lashera.cart.v1`.
مفيش سيرفر ولا داتابيز — الموقع كله ستاتيك.
