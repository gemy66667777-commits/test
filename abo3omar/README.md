# أبو عمر للأجهزة المنزلية — الموقع + لوحة التحكم

موقع كامل للمعرض مع لوحة تحكم. HTML و CSS و JavaScript خام — من غير build ولا مكتبات
خارجية ولا أي طلب لسيرفر بره الموقع. الخطوط مستضافة محليًا.

## التشغيل محليًا

```bash
python3 -m http.server 8000
```

وافتح `http://localhost:8000`.

## الرفع على Vercel

الموقع ستاتيك بالكامل — ارفع الفولدر زي ما هو (Drag & drop في Vercel، أو Import
من GitHub واختار الفولدر ده كـ Root Directory). مفيش إعدادات build.

بعد ما تعرف الدومين النهائي، غيّره في `index.html` عشان صورة المشاركة (الثامبنيل)
تظهر صح على فيسبوك وواتساب:

```bash
sed -i 's|abo3omar-store.vercel.app|الدومين-بتاعك.vercel.app|g' index.html
```

وبعدين افتح فيسبوك ديبَجر (developers.facebook.com/tools/debug) وحط اللينك
واضغط **Scrape Again** عشان فيسبوك يحدّث الكاش.

## العروض

كل عرض = **أجهزة بكمياتها** + **سعر العرض**.

- **عدد الأجهزة** بيتحسب لوحده من مجموع الكميات.
- **السعر قبل العرض** بيتحسب لوحده من (سعر الجهاز × كميته).
- لو غيّرت سعر جهاز، كل العروض اللي فيه بتتحدّث لوحدها.

تقدر تكتب سعر قبل العرض يدوي أو عدد أجهزة يدوي، واللوحة هتحذّرك لو المكتوب مختلف
عن المحسوب.

| العرض | الأجهزة | قبل | بعد | التوفير |
|---|---|---|---|---|
| جهاز العروسة الكامل | ٥ | ١١٧٬٠٠٠ | ١٠٦٬٠٠٠ | ١١٬٠٠٠ |
| عرض المطبخ الصغير | ٤ | ١٨٬٤٠٠ | ١٦٬٥٠٠ | ١٬٩٠٠ |
| عرض البداية | ٣ | ٥٩٬٠٠٠ | ٥٤٬٥٠٠ | ٤٬٥٠٠ |
| عرض الغسيل الكامل | ٢ | ٥٥٬٠٠٠ | ٥١٬٥٠٠ | ٣٬٥٠٠ |
| عرض الصيف | ٢ | ١١٬٧٠٠ | ١٠٬٨٠٠ | ٩٠٠ |

## ⚠️ محتاج مراجعة قبل النشر

1. **كل الأسعار تقديرية** ومبنية على متوسط السوق المصري للأجهزة. راجعها من تبويب
   **الأجهزة** والعروض هتتحدّث لوحدها.

2. **كل العروض الخمسة مقترحة مني**، مش عروض حقيقية من المحل. راجع محتواها وأسعارها
   أو احذفها من تبويب **العروض**.

3. **مواصفات الأجهزة** (السعات، الضمانات، الموديلات) مكتوبة من اللي ظاهر في الصور
   ومن المعتاد للماركة — راجعها مع بيانات الوكيل.

4. **٣ أجهزة من غير صور** (ثلاجة ١٤ قدم، ثلاجة ١٨ قدم، خلاط) بتظهر برسمة بديلة
   مكتوب عليها «الصورة قريبًا». صوّرها وارفعها من اللوحة.

5. **العنوان ناقص** — الظاهر في الصفحة كان مقطوع: «أول شارع جمال عبد النا…».
   حطّيت «أول شارع جمال عبد الناصر» — أكّده وعدّله من تبويب **الفروع** لو غلط.

6. **قسم آراء العملاء فاضي** — لما تجمع سكرين شوت رسايل زباين، ضيفها من اللوحة
   وهيظهر القسم لوحده.

7. **كلمة سر اللوحة** لسه `123456`.

## إيه اللي في اللوحة

| التبويب | بيعمل إيه |
|---|---|
| نظرة عامة | أرقام سريعة + آخر الطلبات + الطلبات حسب النوع |
| الأجهزة | إضافة/تعديل/ترتيب/حذف — ورفع الصور من الموبايل أو الكمبيوتر |
| العروض | اختيار الأجهزة **بكمياتها** + بوستر العرض + تحديد العرض المميّز |
| الأقسام | إضافة وتعديل التصنيفات (مش هيسيبك تحذف قسم فيه أجهزة) |
| المعرض | صور «من جوه المعرض» |
| آراء العملاء | سكرين شوت رسايل الواتساب |
| الفروع | العناوين ولينكات الخريطة |
| الطلبات | كل طلب جاي من الموقع + تغيير الحالة + تصدير CSV |
| الإعدادات | بيانات البراند والأرقام والأسعار + نسخة احتياطية |

## قايمة الطلب

العميل يضيف اللي عايزه (بيظهر إشعار من غير ما تتقفل عليه الشاشة)، والقايمة محفوظة
في المتصفح لو قفل ورجع. زرار واحد بيفتح واتساب برسالة فيها كل الأجهزة والكميات
والإجمالي ومكان للاسم والمحافظة والعنوان.

## التخزين

كل البيانات في `localStorage` تحت المفتاح `abo3omar.v1`، وقايمة الطلب تحت
`abo3omar.list.v1`. مفيش سيرفر ولا داتابيز — الموقع كله ستاتيك.

**يعني إيه:** التعديلات اللي بتتعمل من اللوحة محفوظة **على الجهاز اللي عدّلت منه بس**.
عشان تنقلها لجهاز تاني أو تخليها هي الأصل للكل: **الإعدادات ← تصدير نسخة احتياطية**،
وبعدين استوردها على الجهاز التاني، أو ابعتهالي أحطها في `data.js`.

## الاختبار

اتعمل على Chromium (ديسكتوب ١٢٨٠ وموبايل ٣٩٠):
صفر أخطاء جافاسكريبت، مفيش تمرير أفقي، كل الصور بتحمّل، البحث والفلاتر والقايمة
واللايت بوكس شغالين، رسايل الواتساب مظبوطة، ولوحة التحكم (دخول + تعديل) بتتحدّث
في الموقع على طول.
