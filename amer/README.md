# سنتر الأمير والأميرة — أجهزة كهربائية وموبيليا ومفروشات

موقع كامل للسنتر + لوحة تحكم. HTML و CSS و JavaScript خام، من غير أي build ولا مكتبات خارجية ولا أي طلب لسيرفر بره الموقع.

## التشغيل

افتح `index.html` مباشرة، أو شغّل سيرفر محلي:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الملفات

```
index.html              الموقع
admin.html              لوحة التحكم
assets/css/style.css    ستايل الموقع
assets/css/admin.css    ستايل اللوحة
assets/css/fonts.css    تعريفات الخطوط
assets/fonts/           خطوط Readex Pro و Baloo Bhaijaan 2 و Oswald مستضافة محليًا
assets/js/data.js       البيانات (الأقسام، المنتجات، العروض، المعرض، الإعدادات)
assets/js/store.js      طبقة التخزين
assets/js/app.js        منطق الموقع + قايمة الطلب
assets/js/admin.js      منطق اللوحة
assets/img/             صور المنتجات والمعرض + اللوجو + صورة المشاركة
```

## الدخول للوحة

`admin.html` — الدخول بأي رقم من أرقام السنتر:

| الحقل | القيمة |
|---|---|
| رقم الإدارة | `01229445542` أو `01202676940` أو `01287329932` أو `01227047007` |
| كلمة السر | `123456` |

الأرقام بتتعدّل من تبويب **الأقسام والأرقام**، وكلمة السر من **الإعدادات**.

## الفكرة الأساسية: كل قسم ورقمه

كل منتج مربوط بقسم، وكل قسم ليه رقم واتساب مخصص.
لما العميل يضيف حاجات لـ **قايمة الطلب**، الموقع بيقسّمها لوحده حسب القسم،
وكل مجموعة ليها زرار بيبعت لرقم القسم الصح من غير ما العميل يدوّر.

## الأسعار

- **سعر مؤكد واحد:** المفرمة/كبة اللحوم — `1,870 ج.م` مقروء من ملصق مطبوع على العلبة.
- **قراءة من الخط اليدوي:** طقم التوابل `440` وطبق النمر `55` وطبق الخشب `65`.
- **باقي المنتجات:** أسعار تقديرية قريبة من السوق المصري — راجعها وعدّلها من تبويب **المنتجات**.

لو حبيت تخفي الأسعار كلها: **الإعدادات ← إظهار الأسعار في الموقع** (اقفلها)،
وكل الأسعار هتتبدل بجملة «السعر عند الطلب».

## العروض

كل عرض بيتكوّن من منتجات تختارها من اللوحة + سعر العرض.
**السعر قبل العرض والتوفير بيتحسبوا لوحدهم** من أسعار المنتجات، فمفيش رقم هيتناقض مع التاني.
العروض الموجودة دلوقتي بداية جاهزة — راجع أسعارها قبل النشر.

## صورة المشاركة (الثامبنيل)

`assets/img/og-cover.jpg` مقاس 1200×630، ومربوطة في `<head>` عن طريق `og:image`.

**مهم:** الروابط في `index.html` مكتوبة بدومين `https://ameramira.vercel.app`.
لو رفعت الموقع على دومين تاني، غيّره في كل أماكنه عشان الثامبنيل يظهر:

```bash
sed -i 's|ameramira.vercel.app|الدومين-بتاعك.com|g' index.html
```

## التخزين

كل البيانات في `localStorage` تحت المفتاح `amer.v1`، وقايمة الطلب تحت `amer.list.v1`.
مفيش سيرفر ولا داتابيز — الموقع كله ستاتيك.
