# مزايا — أدوات منزلية وتجهيز عرايس

موقع كامل للمحل + لوحة تحكم. HTML و CSS و JavaScript خام، من غير أي build ولا مكتبات خارجية ولا أي طلب لسيرفر بره الموقع.

## التشغيل

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الملفات

```
index.html              الموقع
admin.html              لوحة التحكم
assets/css/style.css    ستايل الموقع
assets/css/admin.css    ستايل اللوحة
assets/css/fonts.css    تعريفات الخطوط
assets/fonts/           خطوط Noto Sans Arabic و Changa و Italiana مستضافة محليًا
assets/js/data.js       البيانات (الأقسام، المنتجات، العروض، المعرض، الإعدادات)
assets/js/store.js      طبقة التخزين
assets/js/app.js        منطق الموقع + قايمة الطلب
assets/js/admin.js      منطق اللوحة
assets/img/             صور المنتجات + اللوجو + صورة المشاركة
```

## العروض — قلب الموقع

كل عرض بيتكوّن من **منتجات تختارها من اللوحة** + **سعر العرض**.

**السعر قبل العرض والتوفير بيتحسبوا لوحدهم** من أسعار المنتجات، فمستحيل يحصل تناقض:
لو غيّرت سعر منتج، كل العروض اللي فيه بتتحدّث لوحدها.

العروض الموجودة دلوقتي:

| العرض | قبل | بعد | التوفير |
|---|---|---|---|
| العروسة الكامل | ١٤٬٧٠٠ | ١٢٬٩٠٠ | ١٬٨٠٠ |
| المطبخ | ١٠٬٢٥٠ | ٩٬٤٠٠ | ٨٥٠ |
| السفرة | ٤٬٠٥٠ | ٣٬٤٩٠ | ٥٦٠ |
| الضيافة | ٢٬٦٧٠ | ٢٬٢٩٠ | ٣٨٠ |
| الفناجين التلاتة | ٢٬٢٥٠ | ١٬٨٩٠ | ٣٦٠ |

## الأسعار

**كل الأسعار اللي في الموقع تقديرية** ومبنية على متوسط السوق المصري — راجعها وعدّلها
من تبويب **المنتجات** قبل النشر، والعروض هتتحدّث لوحدها.

لو حبيت تخفي الأسعار كلها: **الإعدادات ← إظهار الأسعار في الموقع** (اقفلها)،
وكل الأسعار هتتبدل بجملة «السعر عند الطلب».

## قايمة الطلب

العميلة تضيف اللي عايزاه، والقايمة محفوظة في المتصفح لو قفلت ورجعت.
زرار واحد بيفتح واتساب برسالة فيها كل المنتجات والكميات والإجمالي.

## صورة المشاركة (الثامبنيل)

`assets/img/og-cover.jpg` مقاس 1200×630، ومربوطة في `<head>` عن طريق `og:image`.

**مهم:** الروابط في `index.html` مكتوبة بدومين `https://mazaya-home.vercel.app`.
لو رفعت الموقع على دومين تاني، غيّره في كل أماكنه عشان الثامبنيل يظهر:

```bash
sed -i 's|mazaya-home.vercel.app|الدومين-بتاعك.com|g' index.html
```

## التخزين

كل البيانات في `localStorage` تحت المفتاح `mazaya.v1`، وقايمة الطلب تحت `mazaya.list.v1`.
مفيش سيرفر ولا داتابيز — الموقع كله ستاتيك.
