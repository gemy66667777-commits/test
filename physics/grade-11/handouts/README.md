## نطاق ملزمة العزم (حسب الطلب)
- العزم حول نقطة فقط — **بدون الازدواج (couple) وبدون شروط الاتزان**.
- القوة العمودية: `M = F × L`
- القوة المائلة: `M = F × L × sin θ` (بطريقتين: تحليل القوة / المسافة العمودية)
- الإشارات: عكس عقارب الساعة (+) ، مع عقارب الساعة (−)
- المجموع الجبري لعزوم عدة قوى حول نفس النقطة.

## إعادة توليد الـ PDF بعد أي تعديل

الملفات في `src/` بتولّد الـ HTML، والتحويل لـ PDF بمتصفح Chromium:

```bash
cd src
python3 build_moment.py      # -> moment.html
python3 build_quiz.py        # -> quiz.html
chrome --headless --no-pdf-header-footer --print-to-pdf=out.pdf file://$PWD/moment.html
```

- `figlib.py` مكتبة رسم الأشكال (SVG): أسهم القوى، المفصلات، الزوايا، خطوط الأبعاد.
- `figs_moment.py` / `figs_proj.py` أشكال درس العزم / المقذوفات.
- `css.py` تنسيق وألوان الملزمة.
