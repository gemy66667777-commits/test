# معرض حدائق الزهور للعطور — الموقع + لوحة التحكم

موقع كامل للمعرض مع لوحة تحكم. HTML و CSS و JavaScript خام — بدون build ولا مكتبات
خارجية. الخطوط مستضافة محلياً.

## التشغيل محلياً

```bash
python3 -m http.server 8000
```

## الرفع على Vercel

ستاتيك بالكامل — ارفع الفولدر كما هو. لا توجد إعدادات build.
الدومين مضبوط على `hadaeq-alzohour.vercel.app` — لو كان مختلفاً:

```bash
sed -i 's|hadaeq-alzohour.vercel.app|الدومين-بتاعك.vercel.app|g' index.html
```

ثم **Scrape Again** في فيسبوك ديبَجر لتحديث صورة المشاركة.

## ⚠️ يحتاج مراجعة قبل النشر

1. **باقي الأسعار (١٨ عطراً) تقديرية** مبنية على أسعار السوق السعودي لعطور النيش.
   راجعها من تبويب **العطور**، والباقات ستتحدّث تلقائياً.

2. **الباقات الأربع كلها مقترحة مني** وليست باقات حقيقية من المعرض.
   نِسَب الخصم بين ٦٪ و٩٪ لأن هامش العطور ضعيف. راجعها أو احذفها.

3. **مواعيد العمل** كتبتها تقديراً (٤ العصر – ١٢ منتصف الليل) — عدّلها.

4. **المواصفات** (الأحجام، العائلة العطرية) مكتوبة مما ظهر في الصور ومن المعروف عن
   كل عطر — راجعها.

5. **صور المنتجات قُصّت** لإزالة بانرات السناب والأرقام الصفراء التي كانت فوقها،
   لأنها لا تليق بشكل الموقع. الصور الأصلية محفوظة عندك.

6. **قسم آراء العملاء فارغ.** أضف سكرين شوت رسائل العملاء من اللوحة وسيظهر القسم تلقائياً.

7. **كلمة سر اللوحة** ما زالت `123456`.
