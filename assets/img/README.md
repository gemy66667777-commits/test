# صور المنتجات

ضع صور المنتجات هنا (يفضّل مربّعة 1:1 بمقاس 800×800 بكسل، صيغة jpg أو webp).

ثم في `assets/js/data.js` أضف حقل `img` للمنتج:

```js
{ id:'p02', cat:'maamoul', name:'معمول معجون الروقي', ...,
  img:'assets/img/maamoul-rogi.jpg' }
```

المنتج الذي لا يحتوي على `img` يعرض الرسم التوضيحي (SVG) تلقائياً،
فيمكن إضافة الصور بالتدريج دون كسر الموقع.
