# باهية | BAHIA — متجر مكياج

موقع متجر بصفحة واحدة لبراند **باهية**، مع سلة مشتريات كاملة تُرسل الطلب
إلى واتساب عند الضغط على «إتمام الطلب».

HTML/CSS/JS خام بدون مكتبات ولا خطوات بناء — يشتغل بفتح `index.html` مباشرة.

## كيف تعمل السلة

1. الزائرة تضيف المنتجات (`أضيفي للسلة`) — تُحفظ في `localStorage` فلا تضيع عند تحديث الصفحة.
2. تفتح السلة من أيقونة الحقيبة، وتعدّل الكميات أو تحذف.
3. عند «إتمام الطلب» يُفتح واتساب برسالة جاهزة تحوي كل منتج وكميته وسعره
   والإجمالي، مع حقول فارغة للاسم والمدينة والعنوان.

لا يوجد دفع إلكتروني ولا سيرفر — الطلب يُستكمل في محادثة واتساب.

## الملفات

```
index.html            الصفحة
assets/css/styles.css التصميم
assets/js/data.js     ← الرقم والمنتجات والأسعار (عدّل هذا الملف فقط)
assets/js/site.js     المنطق والسلة والشعار
assets/img/           صور المنتجات
```

## التعديلات الشائعة

- **رقم الواتساب** → `BRAND.whatsapp` (دولي بدون `+`) و `BRAND.whatsappShow`.
- **الأسعار والمنتجات** → مصفوفة `PRODUCTS` (`price` بالريال، و`was` للسعر قبل الخصم).
- **حدّ الشحن المجاني** → `BRAND.freeShipFrom` (اجعله `0` لإلغاء الميزة).
- **الأقسام** → `CATEGORIES`؛ حقل `cat` في كل منتج يطابق `id` القسم.

## بناء نسخة للإرسال أو النشر

```bash
python3 ../tools/build-standalone.py . ../out/bahia.html
```

يُنتج ملفاً واحداً يحوي كل شيء (الصور مضمّنة) ويصلح للفتح بدون إنترنت.
