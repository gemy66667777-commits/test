# الروقي للعطور — موقع عرض المنتجات

موقع تعريفي بصفحة واحدة لبراند **الروقي للعطور (Al Rogi)** — الكويت.
يعرض ١٥ منتجاً بالأسعار، وكل زر طلب يفتح محادثة واتساب جاهزة باسم المنتج.

مبني بـ HTML/CSS/JS خام بدون أي مكتبات أو خطوات بناء — يشتغل بفتح `index.html` مباشرة.

## الملفات

```
index.html            الصفحة (النصوص والأقسام)
assets/css/styles.css التصميم والألوان
assets/js/data.js     ← الأرقام والمنتجات والأسعار (عدّل هذا الملف فقط)
assets/js/site.js     المنطق ورسومات المنتجات (SVG)
```

## التعديلات الشائعة

كل ما يحتاج تعديلاً موجود في **`assets/js/data.js`**:

- **رقم الواتساب** → `BRAND.whatsapp` (بالصيغة الدولية بدون `+`)، والرقم الثاني `BRAND.phone2`.
- **الأسعار وأسماء المنتجات** → مصفوفة `PRODUCTS`.
- **التصنيفات** → `CATEGORIES` (الحقل `cat` في كل منتج يجب أن يطابق `id` التصنيف).
- **آراء الزباين** → `QUOTES`.

## إضافة منتج جديد

أضف عنصراً إلى `PRODUCTS`:

```js
{ id:'p16', cat:'perfume', name:'اسم المنتج', desc:'وصف قصير.',
  size:'٥٠ مل', price:'12.000', badge:'جديد', art:'flacon', tone:['#caa25c','#4a3116'] }
```

- `id` يجب أن يكون فريداً (يُستخدم في تعريفات الـ SVG).
- `art` يقبل: `box` `jar` `dropper` `chips` `burner` `flacon` `pearls` `gift`.
- `badge` اختياري.

## استبدال الرسومات بصور حقيقية

المنتجات معروضة برسومات SVG مولّدة داخل `site.js` (بديل مؤقت عن التصوير).
لاستخدام صور فوتوغرافية بدلاً منها: أضف حقل `img:'assets/img/اسم-الصورة.jpg'` لكل منتج،
ثم في `site.js` داخل `renderProducts` استبدل `${artFor(p)}` بـ:

```js
${p.img ? `<img src="${p.img}" alt="${esc(p.name)}" loading="lazy">` : artFor(p)}
```

يفضّل صور مربّعة (1:1) بمقاس 800×800 بكسل.
