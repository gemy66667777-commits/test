# شذى المدينة للعطورات — موقع عرض المنتجات

موقع تعريفي بصفحة واحدة لمتجر **شذى المدينة للعطورات** — الطائف، سوق البلد.
يعرض ١٥ منتجاً من أقسام المتجر، وكل زر يفتح محادثة واتساب جاهزة باسم المنتج.

HTML/CSS/JS خام بدون مكتبات ولا خطوات بناء — يشتغل بفتح `index.html` مباشرة.

## الملفات

```
index.html            الصفحة (النصوص والأقسام)
assets/css/styles.css التصميم والألوان
assets/js/data.js     ← الأرقام والمنتجات والأسعار (عدّل هذا الملف فقط)
assets/js/site.js     المنطق والأيقونات
assets/img/           صور المنتجات
```

## إضافة الأسعار

كل المنتجات حالياً `price: null` فتظهر بعبارة **«السعر عبر واتساب»** — وهي تناسب
طريقة المتجر الحالية («للاستفسار والطلب»). لعرض السعر، ضع القيمة كنص:

```js
{ id:'s06', ..., price:'85' }      // يظهر: 85 ر.س
```

## التعديلات الشائعة

- **أرقام التواصل** → `BRAND.whatsapp` و `BRAND.phone2` و `BRAND.landline`.
- **المنتجات والأسعار** → مصفوفة `PRODUCTS`.
- **الأقسام** → `CATEGORIES` (حقل `cat` في المنتج يطابق `id` القسم).
- **آراء الزباين** → `QUOTES`.

## الصور

الصور مقصوصة من منشورات حساب `@shathaalmadina` على إنستغرام، بدقّة محدودة
لأن المصدر لقطة شاشة لشبكة المنشورات (١٩٨×١٩٨ بكسل مكبّرة إلى ٥٦٠×٥٦٠).
لاستبدالها: ضع صوراً أصلية مربّعة بنفس أسماء الملفات في `assets/img/`
دون أي تعديل في `data.js`.

## النشر

ملفات ثابتة — ترفع كما هي على GitHub Pages أو Netlify أو Vercel أو أي استضافة.

## ملاحظات على البيانات

- الأرقام والعنوان والأقسام مأخوذة من بايو الحساب الرسمي ومنشوراته.
- **لا توجد أسعار معلنة على الحساب**، لذلك لم تُوضع أي أسعار تقديرية.
- آراء الزباين في `QUOTES` نصوص نموذجية وليست تقييمات حقيقية — استبدلها بتقييمات فعلية.
