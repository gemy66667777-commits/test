# مول السعدني للمفروشات — الموقع + لوحة التحكم

موقع كامل للمحل مع لوحة تحكم. HTML و CSS و JavaScript خام — من غير build ولا مكتبات
خارجية ولا أي طلب لسيرفر بره الموقع. الخطوط مستضافة محليًا.

## التشغيل محليًا

```bash
python3 -m http.server 8000
```

وافتح `http://localhost:8000`.

## الرفع على Vercel

الموقع ستاتيك بالكامل — ارفع فولدر `alsadani` زي ما هو (Drag & drop في Vercel،
أو Import من GitHub واختار الفولدر ده كـ Root Directory). مفيش إعدادات build.

بعد ما تعرف الدومين النهائي، غيّره في `index.html` عشان صورة المشاركة (الثامبنيل)
تظهر صح على فيسبوك وواتساب:

```bash
sed -i 's|alsadani-mafroshat.vercel.app|الدومين-بتاعك.vercel.app|g' index.html
```

|---|---|
| رقم الإدارة | `01097730579` |
| كلمة السر | `123456` |

بيتغيّروا من تبويب **الإعدادات**. **غيّر كلمة السر قبل النشر.**

## العروض — قلب الموقع

كل عرض = **منتجات بكمياتها** + **سعر العرض**.

- **عدد القطع** بيتحسب لوحده من مجموع الكميات.
- **السعر قبل العرض** بيتحسب لوحده من (سعر المنتج × كميته).
- لو غيّرت سعر منتج، كل العروض اللي فيه بتتحدّث لوحدها.

تقدر تكتب **سعر قبل العرض يدوي** أو **عدد قطع يدوي** لو عايز ترقم زي ما هو على البوستر —
واللوحة هتحذّرك لو المكتوب مختلف عن المحسوب.

العروض الموجودة دلوقتي:

| العرض | القطع | قبل | بعد | التوفير |
|---|---|---|---|---|
| عرض المولد ٢ (الرسمي) | ٦٦ | ٢٠٬٠٠٠ | ١٥٬٠٠٠ | ٥٬٠٠٠ |
| جهاز العروسة الاقتصادي | ١٨ | ١٣٬٤٤٠ | ٨٬٥٠٠ | ٤٬٩٤٠ |
| عرض الشتا | ٦ | ٧٬٢٥٠ | ٤٬٢٠٠ | ٣٬٠٥٠ |
| عرض الفوط الكامل | ٢٤ | ٢٬٥٢٠ | ١٬٩٠٠ | ٦٢٠ |
| عرض المفارش | ٥ | ٥٬٥٠٠ | ٤٬٩٠٠ | ٦٠٠ |

## ⚠️ محتاج مراجعة قبل النشر

1. **كل الأسعار تقديرية** ومبنية على متوسط السوق المصري. راجعها من تبويب **المنتجات**
   والعروض هتتحدّث لوحدها.

2. **عرض المولد ٢ هو الوحيد المنقول من بوسترك.** الأربعة التانيين **مقترحين مني** —
   راجع محتواهم وأسعارهم أو احذفهم من تبويب **العروض**.

3. **البوستر نفسه فيه تناقض:** مكتوب «٣١ قطعة» لكن مجموع الأصناف المكتوبة فيه **٦٦ قطعة**.
   الموقع بيعرض **٦٦** لأنه بيحسبها من نفس قايمتك. لو ٣١ هو الصح، عدّل الكميات؛
   ولو عايز تسيب الرقم ٣١ زي البوستر، اكتبه في خانة **عدد القطع المكتوب** في اللوحة.

4. **كلمة سر اللوحة** لسه `123456`.

5. **الأصناف اللي من غير صور** (١٥ صنف) بتظهر برسمة بديلة مكتوب عليها «الصورة قريبًا».
   لما تصوّرها ارفعها من اللوحة مباشرة.

## إيه اللي في اللوحة

| التبويب | بيعمل إيه |
|---|---|
| نظرة عامة | أرقام سريعة + آخر الطلبات + الطلبات حسب النوع |
| المنتجات | إضافة/تعديل/ترتيب/حذف — ورفع الصور من الموبايل أو الكمبيوتر |
| العروض | اختيار المنتجات **بكمياتها** + بوستر العرض + تحديد العرض المميّز |
| الأقسام | إضافة وتعديل التصنيفات (مش هيسيبك تحذف قسم فيه منتجات) |
| المعرض | صور «من جوه المحل» |
| آراء العملاء | سكرين شوت رسايل الواتساب |
| الفروع | العناوين ولينكات الخريطة |
| الطلبات | كل طلب جاي من الموقع + تغيير الحالة + تصدير CSV |
| الإعدادات | بيانات البراند والأرقام والأسعار + نسخة احتياطية |

## قايمة الطلب

العميل يضيف اللي عايزه (بيظهر إشعار من غير ما تتقفل عليه الشاشة)، والقايمة محفوظة في
المتصفح لو قفل ورجع. زرار واحد بيفتح واتساب برسالة فيها كل المنتجات والكميات والإجمالي
ومكان للاسم والمحافظة والعنوان.

## التخزين

كل البيانات في `localStorage` تحت المفتاح `sadani.v1`، وقايمة الطلب تحت `sadani.list.v1`.
مفيش سيرفر ولا داتابيز — الموقع كله ستاتيك.

**يعني إيه:** التعديلات اللي بتعملها من اللوحة محفوظة **على الجهاز اللي عدّلت منه بس**.
عشان تنقلها لجهاز تاني أو تخليها هي الأصل للكل: **الإعدادات ← تصدير نسخة احتياطية**،
وبعدين استوردها على الجهاز التاني، أو ابعتهالي أحطها في `data.js`.

## الاختبار

اتعمل على Chromium (ديسكتوب ١٢٨٠ وموبايل ٣٩٠):
صفر أخطاء جافاسكريبت، مفيش تمرير أفقي، كل الصور بتحمّل، البحث والفلاتر والقايمة
واللايت بوكس شغالين، رسايل الواتساب مظبوطة، ولوحة التحكم (دخول + تعديل) بتتحدّث
في الموقع على طول.
