# مول السعدني للمفروشات — موقع العروض والمنتجات

موقع بصفحة واحدة لـ **مول السعدني للمفروشات** (طنطا) — يعرض عروض جهاز العروسة
والمنتجات بالأسعار، وكل زر طلب بيفتح واتساب برسالة جاهزة.

HTML/CSS/JS خام — من غير أي مكتبات أو خطوات بناء. بيشتغل بفتح `index.html` على طول.

## الملفات

```
index.html              الصفحة (الأقسام والنصوص الثابتة)
assets/css/styles.css   التصميم والألوان
assets/js/data.js       ← الأرقام والعروض والمنتجات والأسعار (عدّل ده بس)
assets/js/site.js       المنطق: السلة، الفلاتر، رسايل الواتساب
assets/img/             الصور
```

## ⚠️ حاجات لازم تتراجع قبل النشر

1. **أسعار المنتجات مبدئية** — كل الأسعار في `PRODUCTS` تقديرية من السوق، مش أسعارك الحقيقية.
   راجعها كلها وعدّلها.
2. **٣ عروض من الأربعة مقترحة** — «جهاز العروسة الاقتصادي» و«عرض الشتا» و«عرض الفوط الكامل»
   أنا اللي ركّبتها كمقترح، مش عروض حقيقية عندك. اتأكد من محتواها وأسعارها أو احذفها.
   العرض الوحيد المنقول حرفياً من البوستر الرسمي هو **«عرض المولد ٢»**.
3. **ملاحظة على بوستر عرض المولد ٢:** العنوان مكتوب فيه «٣١ قطعة»، لكن مجموع القطع
   المذكورة في تفاصيل العرض نفسه **٦٦ قطعة**. الموقع بينقل البوستر زي ما هو —
   لو الرقم غلط في البوستر، صلّحه في `OFFERS` (الحقل `sub`).
4. **مواعيد العمل** في `BRAND.hours` مكتوبة تقديري (١٠ ص – ١١ م) — عدّلها.
5. **روابط الخرايط** في `BRAND.branches[].map` بحث بالاسم على جوجل مابس.
   الأفضل تستبدلها بلينك الموقع الحقيقي من Google Maps.

## التعديلات الشائعة

كل حاجة في **`assets/js/data.js`**:

- **أرقام الواتساب والتليفون** → `BRAND.whatsapp` / `whatsapp2` / `phone`
  (بالصيغة الدولية بدون `+`، يعني `201015908083`)، ومعاهم `whatsappShow` وإخواتها
  للشكل اللي بيظهر على الشاشة.
- **العناوين** → `BRAND.branches`
- **الأسعار وأسماء المنتجات** → مصفوفة `PRODUCTS`
- **العروض** → مصفوفة `OFFERS`
- **التصنيفات** → `CATEGORIES` (لازم `cat` في المنتج يطابق `id` التصنيف)

## إضافة منتج جديد

```js
{ id:'s18', cat:'towels', price:320, was:400, img:'assets/img/اسم-الصورة.jpg',
  name:'اسم المنتج', desc:'وصف قصير للخامة والمقاس.', badge:'جديد' }
```

- `id` لازم يكون فريد.
- `cat` من: `beds` `blankets` `quilts` `towels`
- `img` اختياري — من غيره بتظهر رسمة بديلة مكتوب عليها «الصورة قريباً».
- `was` اختياري (السعر قبل الخصم).
- `price: null` → بيظهر «السعر على واتساب» وزرار يسأل بدل ما يضيف للسلة.

## إضافة عرض جديد

```js
{ id:'newoffer', kicker:'عرض مقترح', title:'اسم العرض', sub:'وصف قصير',
  price:9000, was:11000,
  groups:[ { icon:'bed', title:'أطقم السرير', items:['٢ طقم سرير كبير'] } ] }
```

- `icon` من: `bed` `towel` `blanket` `quilt` `robe`
- `featured:true` بيخلي العرض يظهر كبير في الأول (عرض واحد بس).

## الصور

المنتجات اللي من غير صور بتظهر برسمة بديلة عليها «الصورة قريباً — اسأل على واتساب».
لما تصوّر صنف، حطّ الصورة في `assets/img/` وضيف `img:'assets/img/الاسم.jpg'` للمنتج.
يفضّل صور مربّعة (1:1) بمقاس 800×800 أو أكبر.

## السلة

السلة بتتخزّن في متصفح الزبون (`localStorage`) وعند تأكيد الطلب بتفتح واتساب
برسالة فيها كل المنتجات والكميات والإجمالي، وسايبة مكان للاسم والمحافظة والعنوان.
المنتجات اللي `price: null` مش بتتضاف للسلة عشان مالهاش سعر.

## النشر

ملفات ثابتة — ارفع المجلد زي ما هو على GitHub Pages أو Netlify أو Vercel
أو أي استضافة عادية.

## الاختبار

اتعمل على Chromium (ديسكتوب ١٢٨٠ وموبايل ٣٩٠):
كل الصور بتحمّل، مفيش أخطاء جافاسكريبت، مفيش تمرير أفقي، والسلة وروابط الواتساب شغالة.
